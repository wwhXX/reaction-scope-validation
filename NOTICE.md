# Provenance and attribution notice

## Independent project identity

`reaction-scope-validation` is an independent research repository for auditing
decision-space validity and reaction-boundary recovery. It is not an official
ScopeMap distribution, replacement, endorsement, or sequel.

## Inherited components

The repository began from a ScopeMap code distribution. The following areas
contain inherited or directly adapted baseline material:

- `ScopeMap/`
- `SubstrateScore/`
- legacy scripts and datasets under `Examples/` and `Data/`

The distributed license identifies the original copyright holder as:

```text
Copyright (c) 2026 DeepSynthesis
```

Those components remain covered by the MIT license in `LICENSE`. Their original
names are retained where needed for reproducibility and do not define the name
or claims of this repository.

## Independent benchmark extensions

The `experiments/` workflow adds paired decision-space contrasts,
boundary-sensitive metrics, robustness analyses, external reaction-yield
controls, result summarization, and manuscript/SI assembly. These extensions
frame ScopeMap landscapes as case studies within a broader reaction-scope
validation problem.

## Data sources

Dataset names and source-specific identifiers are retained so that results can
be traced to their published origins. Inclusion in this repository does not
transfer ownership of upstream datasets or publications. Users should consult
the cited sources and comply with their applicable terms.
